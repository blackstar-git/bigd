R Programming – Practical Exam Cheat Sheet
Only commonly used R syntax, functions and commands required for basic RStudio practicals.
1. Basic R Commands
Syntax / Function
Purpose
getwd()
Displays current working directory.
setwd("path")
Changes working directory.
print(x)
Displays output.
cat()
Prints formatted output.
#
Adds comments.
ls()
Lists objects in the workspace.
rm(x)
Deletes an object.
help(mean) or ?mean
Displays function documentation.
example(mean)
Shows examples of a function.
source("file.R")
Executes an R script.
install.packages("ggplot2")
Installs an R package.
library(ggplot2)
Loads an installed package.

Purpose

9. Functions in R
Syntax / Function
Purpose
function()
Defines a user-defined function.
return()
Returns a value from a function.
apply()
Applies a function to matrix rows or columns.
lapply()
Applies a function to each list element.
sapply()
Applies a function and simplifies the result.
tapply()
Applies a function to groups of data.
ifelse()
Performs conditional selection.

Example of a user-defined function:
calculate <- function(a,b) {
  sum <- a+b
  return(sum)
}

calculate(10,20)

12. Important Practical Programs
These are useful basic implementations to practise before the examination.
1. Basic calculations
a <- 10
b <- 20
sum <- a+b
print(sum)
2. Vector operations
x <- c(10,20,30,40,50)
mean(x)
sum(x)
max(x)
min(x)
3. Creating a data frame
name <- c("A","B","C")
marks <- c(80,90,75)

data <- data.frame(name,marks)
print(data)
summary(data)
4. Reading a CSV
data <- read.csv("data.csv")
head(data)
summary(data)
5. Filtering data
subset(data, marks>80)
6. Bar plot
barplot(data$marks,
        main="Student Marks",
        xlab="Students",
        ylab="Marks",
        col="blue")
7. Histogram
hist(data$marks,
     main="Marks Distribution",
     xlab="Marks",
     col="green")
8. Pie chart
pie(data$marks,
    main="Marks Distribution",
    col=rainbow(length(data$marks)))
9. Scatter plot
plot(data$marks,
     main="Marks Scatter Plot",
     xlab="Students",
     ylab="Marks",
     col="red")
10. Box plot
boxplot(data$marks,
        main="Marks Box Plot",
        ylab="Marks",
        col="orange")
